# 暖阳叮嘱（小程序端显示名"暖阳叮嘱"）- 适老化工具微信小程序

## 项目简介
"暖阳叮嘱"是一款专为 **60 岁以上老年人** 设计的适老化（无障碍）微信小程序，小程序端展示名为"暖阳叮嘱"。它把老年人日常最高频的三件事——**看天气、吃药提醒、紧急呼叫家人**——整合进一个大字体、高对比度、零学习成本的极简工具里，帮助老年用户和帮助父母长辈使用手机的家属解决"字太小看不清、功能太复杂不会用、忘记吃药、遇到紧急情况不知道找谁"等真实痛点。项目基于原生微信小程序 + 微信云开发（云函数 + 云数据库）构建，天气数据来自和风天气 API，核心页面同时被打包为 Android / iOS 原生 App（见 `miniapp/` 目录）。

## 核心功能
- **天气查询**：自动定位，展示实况天气、未来 3 天预报、穿衣建议等生活指数，大字号呈现，一眼看清今天冷不冷、要不要加衣服。
- **用药提醒**：新增/编辑/删除用药计划（药名、剂量、服药时间段），到点通过微信订阅消息推送提醒，标记"已服用"，避免老年人漏服、错服、重复服药。
- **紧急联系人一键拨号**：维护家人/子女的紧急联系人列表（姓名、电话、头像、置顶），列表点击即可一键拨打电话，无需翻找通讯录，遇到突发情况能第一时间联系到家人。
- **适老化交互**：大字体、高对比度配色、简化操作路径，专为视力退化、操作不熟练的老年用户优化。

## 适合谁 / 使用场景
- 60 岁以上、对智能手机操作不熟悉的老年用户，想要一个"打开就能看懂"的天气 + 吃药 + 打电话工具。
- 需要远程帮父母/长辈设置用药提醒和紧急联系人的子女、家属。
- 需要一个适老化（老年模式）微信小程序参考实现的开发者，可参考本项目的云开发架构、订阅消息推送、和风天气 JWT 鉴权接入方式。

## 常见问题
**这是做什么的小程序？**
一个面向老年人的适老化小程序，核心功能是天气查询、用药提醒、紧急联系人一键拨号。

**老年人忘记吃药怎么提醒？**
在"用药提醒"页面添加用药计划并设置服药时间段，到点会通过微信订阅消息推送提醒，并可在页面标记"已服用"、查看服药倒计时。

**老年人遇到紧急情况怎么联系家人？**
在"联系人"页面预先添加家人的姓名和电话，之后只需点击对应联系人卡片即可一键拨号，无需查找通讯录。

**这个小程序除了小程序端还有 App 吗？**
`miniapp/` 目录包含将该小程序打包为 Android / iOS 原生 App 的配置，核心功能与小程序端一致。

## 快速开始

### 1. 开通云开发
1. 在微信开发者工具中打开本项目
2. 点击工具栏"云开发"按钮，开通云环境
3. 记录云环境ID，替换 `miniprogram/app.js` 中的 `your-env-id`

### 2. 创建云数据库集合
在云开发控制台 -> 数据库中创建集合：
- **medications** — 用药记录集合
  - 字段：_openid, name, dosage, time, periodLabel, status, takenAt, createdAt, subscribeCount
  - 权限：仅创建者可读写

### 3. 配置和风天气 API（JWT 鉴权）
1. 访问 https://dev.qweather.com/ 注册账号，创建项目，记录**项目ID**
2. 本地生成 Ed25519 密钥对（终端执行）：
   ```bash
   openssl genpkey -algorithm ed25519 -out ed25519-private.pem
   openssl pkey -in ed25519-private.pem -pubout -out ed25519-public.pem
   ```
3. 在控制台该项目下"创建凭据"，上传 `ed25519-public.pem` 的公钥内容，获得**凭据ID（KID）**
4. 在云开发控制台 -> 云函数 -> getWeather -> 配置 -> 环境变量中添加：
   - `QWEATHER_PROJECT_ID`：第1步的项目ID
   - `QWEATHER_KEY_ID`：第3步的凭据ID
   - `QWEATHER_PRIVATE_KEY`：`ed25519-private.pem` 的完整内容（PEM 多行文本可直接粘贴；若环境变量只支持单行，把换行替换成字面量 `\n` 再粘贴，代码会自动还原）
5. （可选）新版和风天气账号会在控制台"我的项目"里分配专属 API Host（形如 `https://xxxxxx.qweatherapi.com`），如果天气获取报 403/404，再添加：
   - `QWEATHER_API_HOST`：你的专属 API Host（不填则默认使用旧版共用域名 `https://devapi.qweather.com`）

> 私钥文件（`ed25519-private.pem`）只用来配置环境变量，不要提交到代码仓库。

### 4. 部署云函数
在微信开发者工具中：
1. 右键 `cloudfunctions/getWeather` -> "上传并部署：云端安装依赖"
2. 右键 `cloudfunctions/saveMedication` -> "上传并部署：云端安装依赖"
3. 右键 `cloudfunctions/medicationReminder` -> "上传并部署：云端安装依赖"
4. 右键 `cloudfunctions/saveContact` -> "上传并部署：云端安装依赖"

### 5. 配置订阅消息（可选）
1. 在微信公众平台 -> 功能 -> 订阅消息中申请模板
2. 替换以下文件中的 `your-template-id`：
   - `miniprogram/pages/medication/index.js`
   - `cloudfunctions/medicationReminder/index.js`

### 6. 替换 AppID
替换 `project.config.json` 中的 `your-appid` 为你的小程序AppID
